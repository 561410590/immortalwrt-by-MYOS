# MYOS-NEW

适用于当前 OpenWrt / ImmortalWrt LuCI ucode 界面的通用主题，包架构为 all。

同一份源码、同一个包读取 system.board 的 model/board_name，选择 N5000、C2000-Ultra、C2000MAX、NBCPE-688、C5800-688、C8-688 对应的产品图。未知型号显示通用设备标记，安装不限制机型。其他机型的实时字段依据设备可提供的数据展示，未获取的数据不冒充正常值。

首页顶部展示 CPU、内存、温度、存储；左栏连续排列蜂窝、网口、网络、终端，右栏连续排列产品图、实际流量柱状图、无线、版本，两栏保持一致宽度和间距，不用跨行卡片相互撑出空白。窄屏改为单栏。流量按外网设备去重，使用计数增量与实际采样间隔。状态接口只读，不控制拨号、路由、SIM 或网络服务。已移除服务状态卡片及首页标语。

侧栏搜索统一位于首页之前。品牌和 favicon 使用用户提供的原始 MYOS PNG。默认深色毛玻璃，保留浅色切换和手机导航。菜单展开/收起使用可打断的临界阻尼弹簧，同级菜单保持单个展开；页面进入使用轻微位移和渐显；遵循减少动态、减少透明度及增强对比度偏好。原无线和 C5800 模组状态页接入同一组材质与颜色变量。保留已有 MYOS/MWRT 功能页面的入口，不卸载承载这些功能的旧软件包。

## 加入源码树

将本目录放入 OpenWrt 源码 package/luci-theme-myos-new，选中 CONFIG_PACKAGE_luci-theme-myos-new=y 后随下一版构建；也可以单独编译软件包：

```sh
make package/luci-theme-myos-new/compile CONFIG_PACKAGE_luci-theme-myos-new=m
```

安装规则明确将目录设为 0755、公开静态资源和模板设为 0644、uci-defaults 入口设为 0755。安装后注册并选用 MYOS-NEW；既有固件自己的组装脚本若覆盖默认主题，应在该固件构建安排中处理，而不是修改通用包加入机型门禁。

## 本次版本

1.0.4-r2：修正 SIM 名称缓存 chmod 的参数格式，使用 nixio 接受的八进制字符串，避免刷新云端名称时返回 HTTP 500。连接数及上限始终读取内核真实值，不写死为 65535，也不改变系统设置。

1.0.4-r1：兼容 Ultra QModem 的合并 cache_info 与分散缓存，恢复运营商、精确网络制式、信号、小区、模组温度及数据接口；区分已选和实际 SIM 卡槽。Ultra 蜂窝管理入口进入 QModem 概览，物理端口按桥成员标注 WAN/LAN。降低卡片、侧栏和工具栏的不透明度，保留静态背景、现有模糊、高光及文字对比，不加入实时折射渲染。继承 Ultra 的供应商说明栏与加速状态深色配色。

继承 1.0.2-r4：修正 OpenClash 运行日志被通用表单 flex 横排的问题，日志及底部操作栏恢复整行，按钮图标与文字横向对齐；日志面板接入主题材质。保留减少透明度、减少动态和增强对比度偏好。

右上角全局通知每 10 秒读取一次状态，按首页相同的机型映射观察物理网口；通过 carrier 与 carrier_up_count 识别连接、断开和轮询间短暂重连。首次访问只建立基准，读取失败不报断网。当前标签页会话保存最近状态和 150 秒内的通知，刷新或切换菜单不会把现有网口误当作新插入。USB、无线网桥及其他通知复用固件已有 luci.mwrt-notice 返回项；没有该后端时物理网口通知仍独立可用。LuCI 自身成功、警告和错误通知移入同一右上角玻璃层，保留原内容和按钮。只观察，不控制网络、拨号或服务。

继承 1.0.2-r3：CPU、内存、温度、存储占用前移；展示实际活动连接数和 turboacc 提供的加速类型、PPE 已绑定/总表项；补齐各级菜单的 SVG 图标和 OpenClash 等页面的功能标签；移除产品图下的 MAC 地址。设置向导使用 MYOS-NEW 标识和深色材质；补全接口信息框、悬浮详情、TurboACC 及蜂窝设置页面配色。

已登录页面的空白处连续键入 `myosmyos`，或连续点击侧栏底部固件版本 8 次，打开插件口令框。通过 POST 和 LuCI token 调用 `admin/myos/unlock`，转给固件已有的 `zz_mwrt_fancontrol.action_Outofnetwork` 核验，成功后刷新菜单，不重启设备。适配入口解决原接口仅在 Argon 主题下注册的问题。66.1 当前后端为本机口令核验；其他固件依据各自已有后端处理。主题不更改口令或插件运行状态；缺少原核验后端的固件明确显示接口不可用。

SIM 名称依据原厂 queryTypeByIccid 协议，以完整 ICCID 发送加密 JSON 并解密响应，使用设备已有的 nradio_crypto -O。仅接受成功响应的卡名，“普通卡”也须由云端返回，不能用卡槽类型或请求失败推断。按 ICCID 分别缓存五分钟，查询不阻塞首页状态轮询；失败显示名称暂不可用。可读取原厂 cpestatus 及 QModem SIM 缓存，未安装 nradio_crypto 的系统保留设备现有名称并显示查询不可用，不控制拨号或安装流程。66.166 原厂设备仅用于只读核对协议，不作为主题运行依赖。

包含 1.0.1 的搜索框顺序、LuCI 非当前标签页隐藏、编辑弹窗遮罩、下拉按钮、登录首页选中状态、手机表格溢出、本地时间时区和重复网关修复。

当前源码树另已修复旧向导 RPC 的无参数方法声明：package/luci-theme-mwrt/root/usr/libexec/rpcd/mwrt-wizard 的 status/modem 必须声明为 JSON 对象而非数组。该文件属于原功能包，已同步其持久源码和 C5800 活机；不由新主题 IPK 覆盖。保留此修复后，向导才能读取型号、模组、管理地址和系统版本。

C5800 的频段与小区锁定读取修复在原蜂窝功能包中：`c5800_radio.lua` 与 `c5800_radio_lock.lua` 用进程锁替代会遗留的目录锁；`c5800-radio.js` 在小区读取失败时仍独立读取锁定状态，`radio_controls.htm` 更新脚本缓存版本。这些文件此前已热更新 C5800 并同步原包源码，不属于通用主题 IPK；不执行制式、频段、SIM 或拨号变更。旧 r4 归档包含这组原包修复及向导 RPC，本次 1.0.4 源码归档仅包含通用主题。

本次适配对象为 C2000-Ultra / FC83C618430C，经 MAC 远控操作。用户限定只用内置浏览器；当前控制接口报 native pipe 不可用，因此本版透明效果、动画及窄屏的浏览器绘制验收尚未完成，不用接口返回替代视觉证据。未人为插拔网口或 USB，仅构建主题 IPK，不构建或刷写固件。各设备实测范围以对应开发记忆为准。
