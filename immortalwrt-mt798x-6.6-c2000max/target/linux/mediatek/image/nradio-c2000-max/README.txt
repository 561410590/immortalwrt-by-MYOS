NRadio C2000-MAX SD image assets

These files are copied from the vendor SD card image:
/vol4/1000/immortalwrt/nradio_c2000-max-SD_0305.img

They are used only to build a flashable SD-card raw image matching the vendor layout.
The kernel and rootfs partitions are generated by this source tree.

Vendor SD layout:
bl2        3584K @ 512K
u-boot-env 512K  @ 4096K
factory    4096K @ 4608K
fip        2048K @ 8704K
kernel     32768K @ 10752K
rootfs     200M  @ 43520K

gpt.img is the vendor PMBR + primary GPT area, sectors 0..33.
